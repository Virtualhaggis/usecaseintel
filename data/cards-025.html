IndonesianFoods npm spam package install on developer/CI endpoint AIDelivery High
Hunts for npm/yarn/pnpm install commands referencing the IndonesianFoods TEA Protocol reward-farming spam packages — base names vointea/voinzaril and the suffix families -wekto/-riris/-z3n/-kyuki/-breki/-notthedevs, plus the high-download outlier ksni-technical-test. Catches developers or build agents pulling any of the ~4,000–5,000 derivative spam packages that the auto-publication script seeded onto the registry. Rationale: Pivots on the SPECIFIC base package names (vointea, voinzaril) and suffix families (-wekto, -riris, -z3n) called out by Snyk, augmented with the -kyuki/-breki/-notthedevs suffixes and the ksni-technical-test outlier confirmed in Endor Labs and The Hacker News deep-dives. Any one match against an npm install command line is article-specific and has no benign reading. IndonesianFoods auto-publish artifact (auto.js / publishScript.js) dropped in node_modules AIInstallation High
Detects the IndonesianFoods campaign's auto-publication scripts — auto.js or publishScript.js — being written into a node_modules subfolder whose package name matches the vointea/voinzaril/-wekto/-riris/-z3n/-kyuki/-breki/-notthedevs naming families. Per Snyk and Endor Labs these scripts are the ONLY 'malicious' functionality in the campaign: they re-template the package and republish under a new name to farm tea.xyz rewards. Rationale: Pivots on the article's named automation artifacts (auto.js, publishScript.js — described by Snyk as the publication automation that lacks an exit condition) constrained to node_modules subfolders whose package name matches a confirmed IndonesianFoods family. Both axes have to match, so unrelated repos containing files named auto.js won't fire — only the campaign's actual artifact will. Endor Labs and Hacker News both confirm these scripts as the campaign's core mechanism. Rationale: tea.xyz is the named reward-farming infrastructure in both the Snyk article and corroborating Endor Labs / Hacker News coverage. It's not a domain a typical enterprise developer touches; a hit from a non-research endpoint is a clean pivot for hunting either residual campaign activity or a developer who may have run the publishScript automation. Kept as hunting tier (not alerting) because legitimate TEA Protocol curiosity is plausible.
