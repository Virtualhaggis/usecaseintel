ImageMagick 'convert -resize' command injection via sh -c in Go web app AIExploitation Medium
Hunts Linux shell invocations where a Go service builds an ImageMagick 'convert ... -resize NxN ...' command string and executes it through 'sh -c' (the exact vulnerable pattern in the Snyk article's downloadAndResize function), but the resulting command line carries shell metacharacters or secondary commands injected through the user-controlled fileSize parameter. The legitimate command is a pure numeric resize, so any ;, |, &, $(), backtick or chained rm/wget/curl in a convert command line indicates active command injection. Rationale: Anchored on the article's exact vulnerable construct: exec.CommandContext(ctx, "sh", "-c", "convert %s -resize %sx%s %s") where fileSize is attacker-controlled. The legitimate command is a numeric-only resize, so convert + -resize co-occurring with shell metacharacters or chained commands is high-fidelity injection evidence. No external IOCs/actor exist to corroborate — this is an educational secure-coding article (fictional 'cloudpawnery' demo app), so no second source was sought; the detection is grounded purely in the published code pattern and the ImageMagick command-injection class.
