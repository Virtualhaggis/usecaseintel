Curl invoked with SOCKS5-hostname resolution (CVE-2023-38545 exploit precondition) AIExploitation Medium
Hunts curl/libcurl-driven processes whose command line enables SOCKS5 hostname resolution (--socks5-hostname or socks5h:// scheme). The cURL maintainer's advisory specifically identifies this configuration as the trigger path for the heap buffer overflow; the detection surfaces hosts where the vulnerable code path is actually being exercised, regardless of whether the binary itself has been patched. Rationale: Anchored on the exact exploit precondition documented by the cURL maintainer and the Snyk advisory: SOCKS5 with hostname resolution (the `socks5h` scheme / `--socks5-hostname` flag). HTTP-redirect-driven exploitation is harder to catch on the endpoint because it depends on attacker-controlled server behaviour, but the SOCKS5-hostname switch is a tight string that's unusual in benign automation.
