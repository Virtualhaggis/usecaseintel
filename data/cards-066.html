npm install-time script executing 'node .' postinstall payload AIInstallation Medium
Hunts the dependency-confusion dropper pattern Snyk flagged: a malicious package whose package.json declares "postinstall": "node .", causing npm to spawn node.exe with the directory ('.') as the entrypoint during install. This surfaces install-time code execution from untrusted packages, distinct from normal build steps like webpack. Rationale: Anchored on the exact malicious postinstall string Snyk called out ('node .') plus an npm/yarn/pnpm install parent context, so it fires on supply-chain droppers rather than legit build hooks. Snyk and JFrog independently confirm postinstall JS invocation as the install-time execution vector. Cross-checked against: • https://snyk.io/blog/snyk-200-malicious-npm-packages-cobalt-strike-dependency-confusion-attacks/ • https://jfrog.com/blog/npm-supply-chain-attack-targets-german-based-companies/
