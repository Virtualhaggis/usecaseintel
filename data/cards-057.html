CISA KEV: CVE-2022-30190 — Microsoft Windows Support Diagnostic Tool (MSDT) Remote Code Execution Vulnerability

CISA KEV
2022-06-14 4 use cases 2 techniques 3 kill-chain phases detected

A remote code execution vulnerability exists when MSDT is called using the URL protocol from a calling application such as Word. An attacker who successfully exploits this vulnerability can run code with the privileges of the calling application. Vendor: Microsoft, Product: Windows. Known ransomware use: Known. Federal patch due: 2022-07-05.
