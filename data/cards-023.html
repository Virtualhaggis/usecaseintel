Lazarus DreamJob DLL side-load: wksprt.exe loading webservices.dll from ProgramData AIInstallation High
Detects the Operation DreamJob side-loading chain where the legitimate Windows Remote Desktop binary wksprt.exe is run from a non-standard ProgramData subfolder (EMC\, Adobe\) and loads a malicious webservices.dll dropped alongside it. This hijack pattern delivers the ScoringMathTea RAT. Rationale: Pivots on the Table 1 side-load chain (wksprt.exe→webservices.dll, wkspbroker.exe→radcui.dll) AND on the article's anomalous host paths (%ALLUSERSPROFILE%\EMC\, \Adobe\, %APPDATA%\Microsoft\RemoteApp\). Legitimate Microsoft Remote Desktop binaries should never execute from these locations.
