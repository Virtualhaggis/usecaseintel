node-ipc/peacenotwar protestware drops WITH-LOVE-FROM-AMERICA.txt on Desktop/OneDrive AIActions on Objectives High
Hunts the signature file artifact written by the peacenotwar module that the article calls out (bundled into node-ipc v11/v9.2.2 and pulled in transitively by installs such as `npm install @vue/cli`). The module writes WITH-LOVE-FROM-AMERICA.txt in five languages to the user's Desktop and OneDrive folders during an npm install — a deterministic, high-fidelity indicator of a poisoned dependency tree. Rationale: Anchored on the exact filename WITH-LOVE-FROM-AMERICA.txt and Desktop/OneDrive drop location confirmed by BleepingComputer, Wikipedia and the GHSA advisory for the peacenotwar/node-ipc incident the article names; the string is unique enough to alert with near-zero FP. Lockfile injection: npm/yarn fetching dependencies from GitHub gist/repo instead of the registry AIDelivery Medium
Hunts the lockfile-injection technique the article details — an attacker edits the `resolved` URL in package-lock.json/yarn.lock to point at attacker-controlled GitHub gist/repo sources. On install, npm/yarn then downloads package tarballs from codeload.github.com / gist.githubusercontent.com / raw.githubusercontent.com rather than registry.npmjs.org, a network shape that betrays a tampered lockfile. Rationale: Directly models the article's lockfile-injection mechanism (attacker-controlled `resolved` key pointing at GitHub gist/repo) by flagging npm/yarn pulling tarballs from GitHub download hosts rather than registry.npmjs.org — the observable network side-effect of a poisoned lockfile. Cross-checked against: • https://snyk.io/blog/npm-security-preventing-supply-chain-attacks/

Phishing-link click correlated to endpoint execution Delivery High
User received an external email containing a URL, clicked it, and within 60 seconds the recipient's endpoint spawned a scripting interpreter or network downloader (PowerShell / cmd / mshta / curl / certutil / bitsadmin). This is the high-fidelity shape — a raw "user clicked an emailed URL" query is too noisy to alert on because every Microsoft 365 tenant generates thousands of legitimate clicks per day. The exec-correlation step suppresses the noise to roughly the rate at which a click actually drives onto-host execution, which is the actionable signal. Pair with UC_PHISH_LINK_BYPASS (Safe Links override) and UC_PHISH_LINK_NEWDOMAIN for orthogonal high-fidelity variants.
