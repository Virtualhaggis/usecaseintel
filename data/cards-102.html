Bower archive extraction arbitrary file write to sensitive paths (CVE-2019-5484 / Zip Slip) AIExploitation Medium
Hunts a `bower install` process (node) writing files into sensitive directories OUTSIDE its bower_components extraction root — the symptom of the tar/tar.gz symlink path-traversal flaw (CVE-2019-5484, pre-1.8.8) and the decompress-zip Zip Slip (pre-1.8.6). A malicious package symlinks a directory like /etc, ~/.ssh or /tmp and a following archive member lands a file on the symlink target, overwriting config or dropping payloads. Article-specific because it ties the write to the bower install context and the exact sensitive targets the advisory calls out. Rationale: Anchors on the article's exact attack mechanic — bower install (node) extracting a crafted archive whose symlink redirects a write outside bower_components into a sensitive path (the advisory cites /etc/passwd). The bower-install command-line + write-to-/etc|~/.ssh|cron|/tmp pairing is far higher fidelity than a bare file-write rule.
