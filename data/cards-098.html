Semicolon GET parameter cloaking in web/proxy logs (cache poisoning, CVE-2021-23336 / CVE-2020-28473) AIExploitation Medium
Hunts inbound HTTP requests whose query string uses a semicolon as a parameter separator (e.g. '?q=cat&utm_content=1;q=dog') — the exact parameter-cloaking primitive Snyk demonstrated against Bottle/Tornado/Rack and Python's parse_qsl.
